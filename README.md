# three
Ein Programm um das Alter des Lehrers herauszufinden, das Alter soll kleiner als 45 sein
Die Zehnerstelle und Einerstelle zusammen ergeben eine zwei Stelle Zahl (also 10 oder mehr)
Die Zehnerstelle ist eine gerade Zahl und die Einerstelle ist eine ungerade Zahl
Um die Einerstelle eine Zahl herauszufinden, soll man die Zahl modulo 10 berechnen (zahl % 10)
Um die Zehnerstelle eine Zahl herauszufinden, soll man die Zall durch 10 dividieren (zahl // 10)

# five
